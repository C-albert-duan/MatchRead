| | |
|---|---|
| **Route** | `/sign-in` |
| **Classification** | Launch MVP |
| **Implementation status** | Partial |
| **Interaction states** | 5 — Idle · Invalid address · Submitting · Check your email · Rate limited |

**Purpose.** The only authentication surface. Magic link, email only — no password, no social provider on web. There is no separate "create account" screen because there is no separate account creation: a first-time address gets an account when it first completes the round trip.

**Entry points**

- Header "Sign in"
- Any authenticated route while signed out (middleware redirect, carrying ?next=)
- An invite link while signed out

**Exit points**

- Check your email (same route, submitted state)
- On callback → the `next` destination, or /leagues

**Required data**

- Email address. Nothing else is collected at any point in the flow.

**Purpose.** The frame every screen renders inside: skip link, wordmark, three nav links, the language control, the session control, and the footer that carries the two sentences the product is legally and ethically required to keep saying. **Required data**
