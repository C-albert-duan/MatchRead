## What is not built

Every item below is classified **Needs Engineering** and is on the launch path.

- **Lightweight onboarding** — POST LAUNCH. The columns exist and the writes are trivial, but nothing on the launch path depends on this: a member with no display name is rendered from their email, and the time zone falls back to the browser at render. Building it in the 38-day window would be spending the scarcest resource on the least-blocking screen.

Individual interactions on otherwise-shipped screens that need engineering:

- Lightweight onboarding → Display name
- Lightweight onboarding → Time zone
- Lightweight onboarding → Skip
- Invite friends → Revoke and re-issue
- Result artifact → Download image
- Settings → Time zone
- System states → Offline
- System states → Provider error
