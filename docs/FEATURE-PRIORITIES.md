# Feature Priorities (CEO)

Source: `Wireframe/MatchRead_US_Open_MVP_Feature_Priorities.pdf`

**Objective:** Create the most engaging digital bracket experience for the US Open. Every feature should increase emotional investment, daily retention, league competition, or organic sharing. Avoid generic tennis-app functionality before launch.

## Tier 1 — Must Have

| Feature | Behaviour | Surfaces on |
|---|---|---|
| **Pick Confidence** | Assign confidence (1–10 or 1–5 stars) to every pick. High-confidence misses create memorable moments. | Bracket entry |
| **Bracket Health** | Status: Elite / Surviving / Hanging On / In Trouble — not only a score. | League home, tournament, Daily Check |
| **Biggest Miss** | Highlight each user's most costly incorrect pick after every round/day. | Daily Check / Recap |
| **Perfect Picks Remaining** | Remaining perfect picks + tournament-wide perfect bracket count. | Bracket locked, league home |
| **Live Leaderboard Movement** | Rank Δ (+/−), biggest climber, new personal best. | Standings, Daily Check |
| **League Highlights** | Auto labels: Biggest Climber, Upset King, Biggest Collapse, Cold Streak. | League home |
| **Daily Recap** | Yesterday's results, biggest upset, league movement, today's key matches. | League home (Daily Check family) |

## Tier 2 — High value if time allows

| Feature | Notes |
|---|---|
| Fan Pick Percentages | Only after lock (integrity: splits hidden until pick/lock) |
| AI Match Insights | No betting advice |
| Upset Alerts | Needs notifications — out of web MVP pull model unless in-app |
| MatchRead Pulse | Per-match impact on bracket, ranking, league chances |

## Tier 3 — Nice to have

Share Cards · Prediction DNA · Trophy Cabinet · Bracket Timeline
